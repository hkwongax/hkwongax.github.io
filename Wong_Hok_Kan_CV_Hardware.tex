\section{Hardware \& Engineering Projects}
\textbf{Autonomous Line-Tracking Robot Car (``Running in HKUST'')} \hfill Fall 2025\\
\textit{Hardware \& Embedded Project \enspace|\enspace Arduino Nano, Breadboard, Optical Sensors, 12V DC Motors, PWM}
\begin{itemize}
  \item Built and wired an autonomous vehicle on an Arduino Nano and breadboard powered by a 12V battery, interfacing an optical bright-sensing array (0V white / 5V black on pins A3--A5) with dual DC motors (D9/D11 PWM, D10/D12 direction).
  \item Calibrated asymmetric DC motor speeds via differential PWM duty cycles above the 100-PWM startup threshold to compensate for motor inertia and maintain accurate straight-line tracking.
  \item Implemented deterministic embedded C/C++ state-machine logic for T/Y/+ junctions, 360\textdegree{} and 180\textdegree{} turns, square/U/S curves, and white-wall bumper reverse-and-stop, completing all 17 tasks in a single take on the first demo trial.
\end{itemize}
