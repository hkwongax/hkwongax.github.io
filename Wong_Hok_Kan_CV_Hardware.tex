\section{Hardware \& Engineering Projects}
\textbf{Autonomous Line-Tracking Robot Car} \hfill Fall 2025\\
\textit{Hardware \& Embedded Project \enspace|\enspace Arduino Nano, Breadboard, Optical Sensors, 12V DC Motors, PWM}
\begin{itemize}
  \item Built and wired an autonomous vehicle on an Arduino Nano and breadboard powered by a 12V battery, interfacing an optical bright-sensing array (0V white / 5V black on pins A3--A5) with dual DC motors (D9/D11 PWM, D10/D12 direction).
  \item Calibrated asymmetric DC motor speeds via differential PWM duty cycles above the 100-PWM startup threshold to compensate for hardware inertia and maintain straight-line tracking.
  \item Implemented deterministic embedded C/C++ state-machine logic for T/Y/+ junctions, 360\textdegree{} and 180\textdegree{} turns, loops, S-curve, and white-wall bumper reverse-and-stop, completing all 17 tasks in ~20 seconds (under the 30s limit) in a single take.
\end{itemize}
\vspace{3pt}

\textbf{Digital Signal Processing, Filtering \& DSB-SC Demodulation Suite} \hfill Fall 2026\\
\textit{Signal Processing Labs \enspace|\enspace MATLAB, FFT, Butterworth IIR Filters, 2D Convolution}
\begin{itemize}
  \item Demodulated dual-carrier DSB-SC audio (20/34 kHz at 132.3 kHz sampling) back to baseband (0--6 kHz) via carrier mixing and a 16th-order Butterworth lowpass filter, and verified Nyquist vs.\ aliasing behavior (20 kHz vs.\ 64 kHz sampling).
  \item Designed an 8th-order Butterworth bandpass filter (4--16 kHz) isolating a 12 kHz tone ($|H|\approx 1.0$) with $-53$ to $-122$ dB stopband attenuation; built 2D Laplacian edge-detection/sharpening filters and a 96 kHz audio echo LTI filter.
\end{itemize}
\vspace{3pt}

\textbf{FoggyTCP \& FoggyHTTP: Low-Level C/C++ Network Protocol Stack} \hfill Sep 2026 -- Nov 2026\\
